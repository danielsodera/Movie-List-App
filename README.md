MOVIE-LIST-APP README 

This app uses React/Javascript/CSS/HTML. 

Aim: Fetch data from TheMovieDb.org when a user searches. The user is then able to mark the movies as their "favourites" or add it to a watchlist. 

Note: The access token and key have been removed from the app.jsx, to try this code yourself, add your own from TheMovieDB.org API. 

Concepts learnt:
- Using an API to fetch data
- Practice with useState and useEffect for searching and populating results
- Event handlers
- Basic CSS
